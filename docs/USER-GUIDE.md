# 使用指南

本指南适用于研知的本地单用户版本。启动方法见 [README](../README.md)，模型连接见 [AI 配置](AI-SETUP.md)。

## 先用示例库体验

首次使用先运行 `npm run setup`，再运行 `npm run demo`。演示默认使用本机 `3135` 端口；在浏览器打开终端打印的文献网址，按 `Ctrl+C` 停止服务。

演示中的 PDF 是项目原创测试文档，笔记、问题和批注是合成示例，AI 强制关闭。程序每次在系统临时目录中新建 `yanzhi-demo-*` 独立知识库，不读取或修改自己的默认 `data/`，也不自动打开浏览器。再次运行会创建新库；需要长期保留的研究资料应在正常 `npm start` 启动的个人库中保存。

## 1. 建立文献库

点击“添加文献”，选择以下一种方式：

- 上传本地 PDF，读取可识别的文档信息后核对保存。
- 输入 DOI、arXiv 标识或网页链接，查询公开题录。
- 手工填写题名与来源，稍后补齐作者、年份、摘要和 PDF。

保存前核对题名、作者、年份和标识。同名文章可能对应不同版本；PDF 创建日期不等于发表年份。查询失败不会妨碍手工建档。

文献可添加多个标签。标签用于筛选；研究问题与想法则用于组织持续研究的上下文，同一篇文章可以关联多个问题。

### 待阅读与列表操作

“全部文献”保留活动文献；“待阅读”是自己挑选的清单。勾选文献后点击“加入待阅读”或“移出待阅读”。移出清单保留文献、PDF、笔记和批注。

文献行尾“…”提供编辑资料、添加 PDF、从来源获取 PDF、关联研究问题与想法、打开来源和移入回收站等操作。常规列表隐藏已回收条目，回收站可以恢复原文献及关联。

### 联网补全文献信息

在“编辑文献信息”中主动选择“联网补全文献信息”。仅有题名时，需要从候选中选择并对比；有 DOI、arXiv 标识或来源时，可以读取公开详情。

对比作者、年份、刊物和标识后，勾选要采用的字段并保存。默认优先填写空缺字段，已有个人笔记不会被题录补全改写。

### 下载与附件版本

“从来源获取 PDF”尝试使用已保存来源、DOI 或 arXiv 标识下载文件。登录页、订阅页和访问验证页不被当作 PDF 保存；受限时可在自己有权访问的浏览器里下载，再手工添加附件。

同一篇文献可保存正文、补充材料和其他版本。新版本创建独立附件，旧批注仍属于原附件，不会自动迁移到不同版本。

## 2. 阅读和批注

打开文献进入 PDF 工作台。支持连续滚动、目录、页码、缩放、适合宽度和旋转；每个附件分别保存阅读位置。

- 选中文字后创建高亮或评论。
- 对图表或没有可选文字的区域，切换区域工具框选。
- 同页可继续选择多处文字，合并为一条批注；间隔文字不会自动加入。
- 将批注插入笔记时，摘录与来源链接一同保存。

来源使用文献 ID、附件 ID 和页码定位。修改批注评论不会自动改写已经插入笔记的摘录。区域批注不生成 OCR 文字；双栏 PDF 的选文顺序也可能受原始文字层影响。

参考文献预览可帮助查看识别到的条目。AI 回答中的来源定位仅用于返回可解析的位置，仍需自己核对原文是否支持相关说法。

“专注阅读”可收起其他区域；退出后恢复原布局。布局和最近打开顺序属于当前浏览器的偏好，不是知识内容备份。

## 3. 写笔记

笔记支持 Markdown、行内和块级 LaTeX、模板、编辑/预览、本地图片和库内文献引用。输入后自动保存；看到“已保存”才表示后端写入成功。

### 图片与文献引用

- 点击“插入图片”，或在编辑器中粘贴、拖入图片，保存到本地知识库。
- 输入 `[[` 并继续输入题名、作者、年份或标识，搜索库内文献；也可点击“引用文献”。
- 选择候选后插入稳定链接，预览中点击可返回文献。
- 常用 Markdown 和公式写法可以在“格式速查”中查找与复制。

预览只渲染本库登记的图片，不自动下载 Markdown 中的外部图片。公式使用 LaTeX 数学语法，不是完整 `.tex` 文档编辑器。

### 保存失败和原稿历史

多个窗口编辑同一笔记时，修订检查会阻止旧稿静默覆盖新稿。遇到保存失败或冲突时，保留当前页面，按提示重试或另存恢复副本。

AI 采纳和历史恢复前会保存原稿快照。历史不是每次按键的完整版本记录；浏览器草稿也不能替代完整备份。

## 4. 组织研究问题与想法

“研究问题”记录持续探索的目标，包含说明、综合笔记和关联材料。“我的想法”可以独立创建，也可关联多篇论文与研究问题。

在想法工作区，一侧“一起推敲”，另一侧“工作笔记”。可拖动中间分隔线调整比例；双击恢复各占一半。聚焦分隔线后，方向键微调，`Home` / `End` 调整到边界。

建议按以下流程使用：

1. 在工作笔记中写出问题、已有判断和不确定之处。
2. 如需 AI，通过“参考资料”明确选取论文摘要、笔记、想法、研究问题或批注；可只选片段。
3. 发送提问并多轮推敲，随时在工作笔记里记下自己的判断。
4. 有阶段认识后点击“整理笔记”，核对预览和来源，再确认追加。

参考资料随已完成的讨论继续沿用，保留的是发送时快照。原材料更新后，需要重新附上才能带入新内容。长期关联管理用于组织知识关系，不代表每轮都会把所有关联内容发送给 AI。

整理默认使用完整成功轮次；可以展开选择整理范围或分段采纳。整理和建议不会在生成时自动覆盖个人正文。“用小结开启新讨论”准备可编辑草稿，确认发送后才调用模型，原讨论继续保留。

## 5. 使用 AI 讨论

AI 可关闭；没有配置时不影响基础知识库功能。提供方的安装、模型与数据流见 [AI 配置](AI-SETUP.md)。论文对话还需要 Poppler 的 `pdftotext`。

### 论文对话

在论文工作台打开“论文对话”。对话按 PDF 附件保存，支持多轮问答、停止、重试、历史重命名和选择本次模型。输入区可以明确加入个人笔记、问题或想法的全文或片段。

页面显示实际读取的页数、页范围、字符数和历史消息数。受长度限制未读取的内容不能作为 AI 已核对的证据。改变页范围或附件时，应核对新一轮的阅读范围。

运行状态区分模型或协议活动、服务器心跳和进程状态。心跳与进程存活说明连接仍在维持，不证明模型正在推理。可以主动停止；已经收到的部分正文、原提问和笔记保留。

使用 `⌘ / Ctrl + Enter` 发送。切换模型影响后续新问题；“重试原提问”沿用原提供方和模型。

### 查找文献并收藏

在支持的“查找文献”入口输入公开题名、DOI、arXiv 标识或来源链接。Codex 的论文对话和想法讨论也可以按要求查询公开题录。

返回的题录和有限摘要不等于读取过 PDF 全文，也不表示文件已经下载。点击来源旁的“收藏”，核对候选及继承的标签，再选择保存或保存并下载 PDF。已有文献优先复用，下载受限时可保留题录，稍后补 PDF。

从当前论文发起时可继承其标签；从想法发起时可选择关联来源文献。请在写入前核对标签和版本；查询期间来源发生变化时，按当前范围重新查询。

多篇查询会排队执行。单次查询失败或本轮检索额度用尽时，模型仍可汇总已经得到的结果；未核实的内容需另行确认。

### 导读与笔记建议

“AI 导读”可以选择正文与补充材料，生成论文纵览、原文重点和分维度分析；关联分析可以比较选定的库内论文。导读和 AI 高亮独立保存，可以按需显示或隐藏。

笔记“AI 辅助”提供轻度润色、梳理问题和研究建议。生成期间可以继续写；采用旧建议前会检查原稿是否已改变。自己核对差异后再采纳，研究建议也可插入光标处或追加末尾。

导读中的原句匹配和页码检查只确认可定位来源，不保证解释、数学证明或研究新颖性正确。

### 导入本机 Codex 讨论与待核验条目

可从“Codex 讨论”入口查看支持读取的本机历史，选择需要的讨论轮次导入。导入保留来源与历史版本，不等于持续同步所有聊天；需要新内容时主动刷新、预览并确认。

研究问题中的待核验条目可记录来源、下一步、核验判断与结果。AI 建议和导入讨论不是已验证结论；解决状态需要自己的判断和结果来源。

## 6. 搜索与分享

搜索覆盖已保存的文献信息、标签、研究问题、笔记、批注和 AI 内容；当前不搜索全部 PDF 的原文。

“PDF 文件夹”会在 `data/share/papers/` 生成便于发送的副本，名称包含可用的年份、第一作者与题名。单篇可以从“…”选择“在文件夹中显示 PDF”。这些副本不包含独立笔记、批注或 AI 内容。

分享目录是累积副本区，元数据变化或回收文献不会自动清理旧副本。修改副本不改写受管理原件；重新整理可重新生成。

## 7. 导出、备份和恢复

三种导出有不同用途：

| 方式 | 用途 | 包含内容 |
| --- | --- | --- |
| Markdown 导出 | 在普通编辑器阅读和继续写作 | 正文与来源附录；全库导出还包含独立 AI 内容及历史 |
| 导出笔记与图片 | 离线阅读图文笔记 | `.tar.gz` 中的 Markdown 与其引用的本地图像 |
| 完整备份 | 恢复研知的整个知识库 | 数据快照、受管理 PDF、笔记图片及相关关系与历史 |

纯 `.md` 中的本库图片链接仍依赖原库。图文包使用相对路径，可以整体解压后阅读，但不恢复完整应用状态。`kb://` 来源链接在外部编辑器中不自动定位原 PDF。

完整备份文件名为 `research-YYYY-MM-DD.kb.json.gz`。它不包含 AI 密钥与机器绝对路径；仍包含个人研究资料，应由自己保管。源库里已经缺失的文件无法通过备份找回。

恢复步骤：

1. 等待当前编辑保存，在“设置与数据”上传完整备份。
2. 校验通过后，程序在当前数据目录旁生成新的目录，保留原库。
3. 复制界面报告的路径，停止本地服务。
4. 在 `.env.local` 中将 `KB_DATA_DIR` 改为该恢复目录，再运行 `npm start`。
5. 刷新页面，核对条目、PDF、图片和来源后继续编辑。

备份适合小型个人库：单 PDF 上限 100 MiB，备份中的 PDF 与图片合计上限 256 MiB；压缩包最大 256 MiB，解压上限 512 MiB。大型库可先停止服务，再完整复制数据目录，保留所有数据库关联文件。

## 8. 常见问题

- **页面打不开**：检查 Node.js 版本、终端输出和端口。默认网址只能本机访问，不是可发给别人的在线服务地址。
- **保存失败**：保留编辑页面和当前文字，先按提示重试或另存，不要把未保存的草稿当成已写入。
- **PDF 无法获取**：尝试公开来源或手动上传；下载器不会绕过登录、付费墙和源站验证。
- **PDF 不能选中文字**：可能没有文字层。当前不提供 OCR，可阅读或使用区域批注。
- **AI 没有回应**：检查提供方、模型、连接测试和运行详情；需要时停止或重试，已收到内容保留。
- **外部修改的 Markdown 没出现**：`data/notes/` 是主库的镜像，不会自动回写；请在应用中编辑或另存导出副本。
- **换电脑后模型不能使用**：知识库备份不复制 AI 账户。请在新电脑自行安装、登录或填写配置。
